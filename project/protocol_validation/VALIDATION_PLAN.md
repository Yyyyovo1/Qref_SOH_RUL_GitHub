# 评估规范有效性验证：回顾性再分析方案

- **状态：** 已由作者确认（2026-11-10）。本方案单独提交并推送之后，才写代码和运行。
- **性质：** 回顾性再分析。只使用已有的预测值和标签，不训练新模型。

## 0. 披露

本方案制定于以下结果之后：SOH 主基准重训核验、换算方式 bootstrap、RUL 先导实验 v1（`7b8dabb`）和 v2（`99ff103`）。制定时已经知道的数字：

- **SOH：** 表面上的 RF/GB 排名反转有 3 处（XJTU first5 的 TRAIN 换算、HUST first 的 TRAIN 换算、XJTU first 的 NOM 换算），受支持的为 0 处。全部 18 个设置的 RF−GB 置信区间都跨 0。
- **SOH，OWN 换算：** 六个“数据集 × Q_ref”设置的点估计排名都是 RF < GB < Ridge。因此按 §1 的主范围，SOH 部分的表面排名变化事先就知道是 **0 次**。
- **SOH，A8 特征集（论文原有结果）：** XJTU 在两种实测参考下 GB 排在 RF 前面，S6 的三个置信区间都跨 0。
- **RUL v1：** 2909 次比较，32 次受支持的反转，其中 E3（单侧误差）30 次。
- **RUL v2：** 3402 次比较，19 次受支持的反转：E1 7 次、E2 6 次、E3（C 指数）6 次。
- **MIT，nominal、θ=0.80：** 严格规则下 43 个严格穿越（精确终点），81 个右删失，且这 81 个结束时的容量都在阈值 1% 以内。Lecu et al. (2026) 报告的也是 43 和 81。
- **换算方式：** “实测参考减 nominal”的 MAE_Q 差值，在 OWN 下 12 个设置的置信区间全部跨 0；在 TRAIN 下有 3 个设置显著升高（XJTU 的 RF first、RF first5、GB first）。因此陷阱 B 的答案事先已知：3 个设置的结论取决于信息条件。

**尚未计算、制定方案时不知道的结果：**

- RUL v2 在 E1、E2 上的表面排名变化次数和噪声基线；
- v2 的 E3 在单侧误差下的受支持反转次数（v2 只存了单侧误差的中位数，没有算置信区间，该文件也没有打开过）；
- 容差规则下各数据集的标签数，以及与严格规则的差异。

## 1. 陷阱 A：把噪声当成排名变化

- **比较单位：** 一次比较 =（数据集, θ, 评估集, 方法对, 一对 Q_ref）。SOH 没有 θ 和评估集，一次比较 =（数据集, 模型对, 一对 Q_ref）。
- **常见做法：** 如果两种 Q_ref 下点估计的优劣顺序不同，记为一次“表面排名变化”。点估计 = 观察到的两种方法电芯误差中位数之差的符号。差值恰为 0 时不计入。
- **按规范的做法：** v2 方案 §1e 定义的受支持反转。
- **比较集合：** 两种做法都只统计 v2 规则下两个设置都可估计的比较（有效电芯 ≥ 5，重抽样缺失 ≤ 5%），保证分母相同。局限：常见做法在现实中不会设电芯数下限，所以这里的表面变化次数是偏保守的。
- **噪声基线（对每个可估计的设置 s 计算，使用现有的 5000 次电芯重抽样）：**
  1. **单次重抽样之间不一致的比例（主指标）：** 把第 b 次与第 b+2500 次重抽样配成 2500 对，统计两次的差值符号不同的比例。这个量反映电芯抽样波动下点估计排名的不稳定程度。
  2. **两半不一致（辅助）：** 前 2500 次和后 2500 次各取 bootstrap 差值的中位数，比较符号是否相同。这个量衡量的是重抽样次数带来的蒙特卡洛误差，预计接近 0。
- **解读限制：** 噪声基线是“同一设置内”的排名不稳定程度，不是表面排名变化的零假设期望值。两种 Q_ref 用的是基本相同的电芯，如果标签完全不变，表面变化次数应为 0。
- **补充量（只作描述）：** 沿用 S7 的口径，对每次比较统计同一次重抽样内两种 Q_ref 的差值符号不同的频率；对出现表面变化的比较，另外统计两种 Q_ref 的符号都与观察到的方向一致的频率。
- **主范围：**
  - SOH 主基准：XJTU、HUST，3 个模型，OWN 换算，共 18 次比较。
  - RUL v2：三个数据集，E1 和 E2。
- **补充范围（单独列出，不并入主结果）：** SOH 的 TRAIN 换算和 NOM 换算（各 18 次比较），以及 XJTU 的 A8 特征集（OWN 换算，9 次比较，输入为 `xjtu_a8_deterministic_reconstruction_v1/xjtu_a8_cell_metrics.csv`）。理由：已知的表面反转都出现在这些地方，OWN 下已知为 0。
- **输出：** 按数据集分别列出比较次数、表面排名变化次数、受支持反转次数、两种噪声基线的平均值。

## 2. 陷阱 B：没有声明评价时使用的信息条件

- **问题的表述：** 用测试电芯自身 Q_ref 换算（OWN）不是错误做法。问题在于没有声明评价时使用了哪些信息：OWN 用到了测试电芯的实测容量，TRAIN 只用训练电芯的信息，两者回答的是不同的问题。
- **设置：** 2 个数据集 × 3 个模型 × 2 种实测参考 = 12 个。
- **计算：** 分别在 OWN 和 TRAIN 换算下，计算“实测参考减 nominal”的中位 MAE_Q 差值及 95% 置信区间，口径与 `reruns/scaling_bootstrap` 相同。
- **结论分类：** 置信区间整体大于 0 为“升高”，整体小于 0 为“降低”，否则为“无法判定”。
- **输出：** 结论取决于信息条件（两种换算下结论不同）的设置数，并逐个列出；同时列出两种换算下点估计的方向，只作描述。
- **规范的要求：** 声明评价时的信息条件，并同时报告两种换算的结果。
- **输入：** 已提交的冻结预测 `project/outputs/soh_primary_benchmark_v1/`。`reruns/scaling_bootstrap` 不在 git 中，只用来做一致性核对。

## 3. 陷阱 C：删失指标有偏

- **范围：** v2 的 E3，三个数据集。
- **反转次数：** 分别用单侧误差（越小越好）和 C 指数（越大越好）统计受支持的反转次数。单侧误差的置信区间需要新算，bootstrap 设置与 v2 相同。
- **预测值偏向：** 对每个（数据集, θ, Q_ref, 方法对）设置：
  - 在两种方法都有预测的“电芯 × t₀”样本上，先在电芯内取平均、再在电芯间取平均，得到各自的平均预测值；
  - 在该指标能判定出更优方法的设置中，统计“平均预测值更大的方法被判为更优”的比例；
  - 单侧误差和 C 指数各算一个比例并对比。平均预测值相等的设置不计入。
- **解读限制：** 预测值更大的方法也可能确实更好，所以有意义的是两种指标之间的差别，不是比例本身的高低。

## 4. 陷阱 D：端点规则的差异

- **容差规则：** 原作者公开披露并做过敏感性分析的端点规则（Lecu et al., 2026），是一种正当的选择。本分析不评价它的对错，只比较严格规则和容差规则给出的标签差异。实现按 BatteryKG 仓库 `src/ingestion/qc.py` 的公开代码（提交 `63b974c`，2026-07-15）：
  1. 对保留的容量序列做滚动中位数平滑：窗口 5，居中，序列两端用窗口内可用的观测（`rolling(window=5, center=True, min_periods=1).median()`）。
  2. 找到平滑序列中第一个 ≤ 阈值的位置，与前一个观测做线性插值，得到阈值交点，作为 EOL；如果这两个平滑值相等，取后一个观测的索引。
  3. 第一个平滑观测就已经 ≤ 阈值时，EOL 记为第一个观测的索引。
  4. 平滑序列没有交点时，如果最后一个**实测**容量 ≤ 阈值 × 1.01，视为在最后一个观测到达 EOL。这类标签记为“仅由容差判定产生”。
- **参数来源：** `smooth_window=5`、`center=True`、`min_periods=1`、`EOL_TOL = 0.01`，容差判断用最后一个实测容量，均与上述代码一致。该代码只在 θ = 0.80 下使用；本方案把同一规则套用到全部 θ 网格。
- **与本研究的差别：** 该代码作用于它自己整理的容量序列；本方案作用于本研究冻结的保留观测（质量控制已排除 44 个 MIT 循环）。另外，它的“初始实测容量”取前 5 个循环的中位数，对应本研究的 first5 参考。
- **端点索引：** 与严格规则相同（XJTU 为累计老化次数，HUST 和 MIT 为循环号）。XJTU 的稀疏批次在严格规则下是区间删失，在容差规则下会因插值而得到点标签。
- **范围：** 三个数据集的全部 Q_ref × θ 设置（3 × 21）。
- **统计：**
  - 严格规则（v2 的端点判定，精确终点才算有标签）和容差规则各自的有标签电芯数；
  - 仅由容差判定产生的标签数；
  - 两种规则下的类别交叉表：严格规则的精确、区间删失、右删失、BASELINE，对容差规则的三类标签（插值交点、首个观测即低于阈值、容差判定）和无标签；
  - 两种规则下都有标签的电芯，容差规则 EOL 减严格规则 EOL 的循环数之差的分布（最小值、四分位数、最大值、|差| ≤ 1 的比例）。
- **合理性检查：** MIT 在 nominal、θ=0.80 下，容差规则应得到 124 个标签，其中 81 个仅由容差判定产生。如果对不上，报告差异和原因，不调参数去凑。
- **局限：** 本项只比较标签数量和 EOL 循环数，不检验容差规则是否改变 RUL 方法的排名。
