## 澄清

1. **陷阱 A 的比较集合：**
   - RUL 只纳入 v2 规则下两个设置都可估计的比较（有效电芯 ≥ 5，重抽样缺失 ≤ 5%）。
   - SOH 各设置都有 55 或 77 个电芯，全部可估计。
   - 表面排名变化要求两个点估计都不为 0、并且符号不同。
2. **噪声基线：**
   - 按设置计算：主指标是第 b 次与第 b+2500 次重抽样的差值符号不同的比例，辅助指标是前后两半各取中位数后符号是否不同。
   - 差值为缺失的重抽样不计入。
   - 汇总时在设置之间取平均。
3. **S7 口径的补充量：**
   - 对每次比较，统计同一次重抽样内两种 Q_ref 的差值符号不同的频率；
   - 另外统计两种 Q_ref 的符号同时与观察到的符号一致的频率。
   - 两者都只作描述。
4. **SOH 的补充范围：** TRAIN 换算和 NOM 换算各 18 次比较；A8 只用 OWN 换算，共 9 次比较。三者单独列出，不并入主结果。
5. **陷阱 B：** 用已提交的冻结预测计算。结论按置信区间分为“升高 / 降低 / 无法判定”；OWN 与 TRAIN 下结论不同的设置，记为“结论取决于信息条件”。
6. **陷阱 C：**
   - E3 的单侧误差使用 E3 的成员集合（各 Q_ref 下全部合格电芯），统计量和 bootstrap 规则与 v2 的误差指标相同，越小越好。
   - 平均预测值的计算范围是两种方法都有预测的合格“电芯 × t₀”样本：先在电芯内取平均，再在电芯间取平均。
   - 汇总中“按规范做仍然成立”的定义：单侧误差下受支持的反转，在 C 指数下同一数据集、同一 θ、同一方法对、同一对设置也受支持，并且两个设置下判定的更优方法都相同。
7. **陷阱 D：**
   - 容差规则作用于各数据集冻结的保留容量序列，按端点索引排序；XJTU 在端点索引相同时再按原始循环号排序。
   - 严格规则的类别来自复算的 v2 标签。
   - 容差规则下“首个观测即低于阈值”的情况单独记为 `FIRST_BELOW`，交叉表中与严格规则的 BASELINE 对应列出。
8. **检查 4 的处理：** 如果对不上，不会中止运行，而是作为结果报告。调试运行中检查 4 已经通过。
9. **检查 2 的参照：** `reruns/scaling_bootstrap` 不在 git 中，因此检查 2 依赖本机文件。S6 来自发布版的 `supplementary/csv/S6_A8_Corrected_CI.csv`。
