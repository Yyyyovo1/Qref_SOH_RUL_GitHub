### 0.2 质量控制 v2 规则是在看到 v1 标签比例之后加上的

- **v1 冻结**（commit `d6c7fa5`）遗漏了一类按 EIS 间隔出现的循环：NCA 约每 26 个循环一次，NCM 约每 51–52 个循环一次。这些循环充电到了 4.2 V，但 1C 放电开始时只有 2.83–3.3 V，只放出 0.02–0.17 Ah。

- **v2 冻结**（commit `22801aa`）只新增一条规则：1C 放电起始电压 ≥ 3.9 V。
  - 依据是放电起始电压明显分成两群：正常循环 3.99–4.09 V，这类循环 2.83–3.3 V，两群之间没有中间值，阈值取在空档中。
  - 规则依据的是放电协议特征，不是容量或标签。
- **v2 冻结的结果：**
  - 465 个循环因这条规则被排除，121 个电芯全部保留；
  - 电芯清单、其他规则、Q_ref 定义和折都不变；
  - v1 的输出保留在 `project/outputs/tju_final_v1/`，不修改，也不再使用。

## 1. 数据

- **来源：** Zhu et al. (2022)，*Nat. Commun.* 13, 2261。Zenodo 概念记录 6379165，版本记录 6405084（v2），CC BY 4.0。
- **冻结：** `project/outputs/tju_final_v2/`（commit `22801aa`），包括电芯清单、循环质量控制、每个循环的容量、Q_ref 和折。
- **两个数据集，分开处理：**
  - NCA：66 个电芯，LG INR18650-35E，标称 3.5 Ah；
  - NCM：55 个电芯，Samsung INR18650-MJ1，标称 3.5 Ah。
  - 9 个混合正极电芯（数据集 3）不纳入。
- **Q_ref：**
  - nominal = 3.5 Ah；
  - first = 第一个合格循环的容量；
  - first5 = 前五个合格循环容量的中位数。
  - Q_ref 两两比较：nominal–first、nominal–first5、first–first5。
- **θ 网格：** 0.60–0.95，步长 0.01，共 36 个点。
- **端点规则：** 严格规则，即 HUST 和 MIT 使用的冻结密集检测器（`detect_hust_eol`）：
  - 第一个容量 ≤ θ·Q_ref 的合格循环，若与前一个合格循环相邻，判为精确终点；
  - 中间隔有排除的循环，判为区间删失；
  - 没有越过阈值，判为右删失；
  - 首个观测已越过阈值，判为 BASELINE。
- **已知的数据特征（披露）：** 两个电芯各有一次单循环容量下凹，它们只标记、不排除，与 HUST 和 MIT 的规则相同：
  - `NCA_CY45-05_1-#17` 在第 204 个循环为 0.567 Ah；
  - `NCM_CY45-05_1-#24` 在第 200 个循环为 0.771 Ah。

  因此严格规则在所有 θ 下都把这两个电芯判为在该循环到达 EOL。

## 3. 方法与特征

### 3.1 方法、超参数和训练方式

与 v2 §5.1 完全相同：

- 四种方法：RF、TRAJ、WAFT、BASE。
- 超参数取自 `rul_ranking_pilot/config.py`：RF 用 `RF_PARAMS`；WAFT 的 L2 惩罚为 0.1；TRAJ 的视野系数为 5.0，对 [t/2, t] 区间的容量做 OLS 外推，回退规则不变。
- 每个训练样本对应 (电芯, t)。
- RF 和 BASE 只用精确电芯训练；WAFT 用全部非 BASELINE 电芯。
- BASE 按 t 分别取中位数。
- WAFT 去掉训练折内取值恒定的列。
- TRAJ 回退比例超过 50% 时，该设置记为不可估计。
- **折：** 使用冻结的 5 折（`tju_cell_fold_assignments.csv`），每个数据集单独划分。

### 3.2 特征

所有特征都只使用原始循环号 ≤ t 的数据或预测时刻已知的信息。

- **容量历史：** 与 v2 相同，包括：
  - C(t)：最后 3 个保留容量的中位数；
  - [t/2, t] 区间上的 OLS 容量斜率；
  - 距阈值余量 C(t) − T；
  - 预测时刻 t。
- **TJU 专用特征**（取自文件名，与论文 Table 1 一致；在测试开始时就已确定，因此在任何 t 都已知）：
  - 环境温度（25、35、45 °C）；
  - 充电倍率（0.25、0.5、1C）。
  - 放电倍率对 NCA 和 NCM 的所有电芯都是 1C，没有信息量，不作为特征。
  - 这两个特征在电芯内恒定，因此直接作为数值特征，不取水平值和斜率。
- **"捷径"说明：**
  - 温度和充电倍率在很大程度上决定了电芯寿命，而同一条件的电芯分布在不同折中。所以模型可以通过"这个条件的电芯通常还能循环多少次"来预测 RUL，而不必真正利用退化信息。这与 v2 中 MIT 的充电时间特征类似。
  - 这种作用在三种 Q_ref 下都存在。结果中会说明这一点，但它不改变判定。
- **测试电芯的 Q_ref** 不作为单独的特征，只通过阈值 T 进入余量特征和 TRAJ，与 v2 相同。
- **特征矩阵的要求：** 除余量特征外，三种 Q_ref 下的特征矩阵逐字节相同，并且不含 Q_ref 列，与 v2 检查 4 相同。

## 4. 评价集、指标、可估计性和反转

与 v2 §1e、§6、§7 完全相同：

- **评价集：** E1、E2、E3；E1_t 只作描述。
- **指标：** E1、E2 用电芯平均绝对误差的中位数；E3 用 C 指数（在每个 t₀ 上至少 10 对可比电芯才计入）。
- **可估计性：**
  - RF 和 BASE：每折训练精确电芯 ≥ 5；
  - WAFT：每折训练事件或区间删失电芯 ≥ 5；
  - 有效测试电芯 ≥ 5；
  - bootstrap 缺失比例 ≤ 5%。
- **bootstrap：** 电芯级配对重抽样 5000 次，种子 20260928，电芯按 Cell_ID 字典序排列，同一数据集内所有设置共用一套重抽样。生成器为 `default_rng(20260928).integers(0, n, (5000, n))`，NCA 的 n = 66，NCM 的 n = 55。
- **更优方法：** 差值的 95% 置信区间不跨 0。E1、E2 的差值为误差之差，越小越好；E3 的差值为 C 指数之差，越大越好。
- **受支持的反转：** 在同一个评价集内，两个设置都判定出更优方法，并且两者判定的更优方法不同。
- **比较单位：** (数据集, θ, 评价集, 方法对, Q_ref 两两比较)。方法对有 6 个：RF–TRAJ、RF–WAFT、RF–BASE、TRAJ–WAFT、TRAJ–BASE、WAFT–BASE。
- **可估计的比较：** 在两个设置下，该方法对的两个配对置信区间都可估计。
- **反转率：** 受支持的反转数 ÷ 可估计的比较数。

## 5. 预测

### 5.1 P0（对照）

- **预测：** first 与 first5 之间的比较，在两个数据集、全部 36 个 θ 和 E1、E2、E3 上合计，受支持的反转**不超过 1 次**。
- **判定：**
  - ≤ 1 次：成立；
  - ≥ 2 次：不成立；
  - first–first5 可估计的比较少于 100 次：无法检验。
- **含义：** 这是对 v2 结果（810 次比较中 0 次反转）的直接复现。如果不成立，说明新数据集或实现可能存在问题，P1 的结果需要谨慎解读，但 P1 的判定规则不变。

### 5.2 P1（覆盖率梯度）

- **范围：** nominal–first 和 nominal–first5 的全部可估计比较，两个数据集合并，E1、E2、E3 合并。
- **分段：** 以**严格规则**下两个设置中**较低**的有标签电芯比例 r 分段，比例按该数据集、该 Q_ref、该 θ 的全部电芯计算：
  - **A 段：** 0.30 ≤ r < 0.60；
  - **B 段：** 0.60 ≤ r < 0.90；
  - r < 0.30 和 r ≥ 0.90 的比较不进入 P1，只作描述。
- **预测：** A 段的反转率 ≥ 2 × B 段的反转率，**并且** A 段的反转率 ≥ 2%。
  - B 段反转率为 0 时，只要 A 段 ≥ 2%，就算满足"2 倍"。
- **检验能力门槛：** A 段或 B 段可估计的比较少于 100 次时，P1 记为"无法检验"。
- **判定：**
  - 两个条件都满足：成立；
  - 任一不满足：不成立；
  - 未达到门槛：无法检验。
- **事先说明的风险：** v2 的总体反转率只有 0.84%，TJU 上很可能也只有极少数反转。如果两段的反转率都接近 0，P1 会判为不成立。这会说明"覆盖率能预测反转"在新数据上没有重现，论文中如实报告。

### 5.3 只作描述的报告（不参与判定）

- P0 和 P1 按数据集（NCA、NCM）、评价集（E1、E2、E3）分开的反转数、比较数和反转率。
- P1 按方法对是否含 TRAJ 分开报告。
- P1 各段除了按评价集计数，另外报告去重后的事件数：按 (数据集, θ, 方法对, Q_ref 两两比较) 计数，不区分评价集。一个事件只要在任一评价集上出现受支持的反转，就计为一次反转事件；只要在任一评价集上可估计，就计为一个可估计事件。
- P1 的 A 段按机制拆开报告：
  - 实测参考一侧比例较低：低端 θ，主要原因是右删失；
  - nominal 一侧比例较低：高端 θ，主要原因是 BASELINE。
- r < 0.30 和 r ≥ 0.90 两段的比较数和反转数。
- 每次受支持的反转逐条列出：数据集、θ、评价集、方法对、两个设置的有标签比例、更优方法。
- 容差规则下各段的划分，只作对照，不重新计算反转。
- v2 的合理性检查结果（见 §7）。
