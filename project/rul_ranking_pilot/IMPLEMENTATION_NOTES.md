## 澄清

1. **WAFT 去掉训练折内恒定的列。**
   - nominal 参考下，CAL 特征里的 `Qref_Ah` 对所有电芯取同一个值。lifelines 内部会按标准差归一化协变量，常数列会导致拟合结果为 NaN：HUST 在 nominal、CAL 下全部 5 折都是这样。
   - 处理：在每个训练折中，去掉取值不变的列，判断只用训练数据。常数列不含任何信息，所以这不改变模型设定。
   - 每折去掉的列数记录在 `preprocessing_audit.csv` 的 `Dropped_Constant_Columns`。
2. **非有限拟合视为不收敛。** 如果 WAFT 拟合出的参数或预测值不是有限数，该设置记为 not estimable，原因记为 `FOLD_k_NONFINITE_FIT`。这对应方案 §4.3 中的“模型不收敛”。
3. **TRAJ 的物理等价检查（检查 2）。**
   - θ′·Q_nominal 与 θ·Q_ref 在浮点运算下可能相差 1 ulp（实测最大 2.2e-16 Ah），所以 TRAJ 预测无法做到逐位相同。
   - 判定规则：缺失值的位置一致，并且最大相对差 ≤ 1e-9。逐位相同的数量和最大差异都会报告。
   - 标签部分仍然要求完全一致，实际也完全一致。
4. **TRAJ 的预测值不截断。**
   - 如果拟合的直线在 n(t₀) 之前就已经穿过阈值，预测 RUL 会是负值，按原值计算误差。
   - 如果需要回退、但训练折中没有 EXACT 电芯可提供回退值，该电芯的 TRAJ 预测记为缺失，计入 `TRAJ_Missing`。
5. **可估计性按整个设置判定。** RF 和 BASE 只要任一折的训练 EXACT 电芯少于 5 个，整个设置的预测全部记为缺失。WAFT 同理。
6. **插补时整列缺失。** 如果某个特征在训练折中全部缺失，用 0 填充。标准化之后 0 就是中性值。
7. **E3 中的区间删失。** 区间按闭区间 [L, U] 处理：预测落在区间内误差为 0，否则取到最近端点的距离。
8. **NOCAL 下的 Q̂_ref。** NOCAL 下的三种方法（RF、WAFT、BASE）都不需要用 Ah 表示的阈值，所以方案 §4.1 里的 Q̂_ref 实际上没有被使用。
9. **HUST 的端点类别。** 在这个 θ 网格上，HUST 没有区间删失的电芯，端点只有 EXACT 和 RIGHT 两类。
10. **依赖。** 新增 lifelines 0.30.3 及其依赖，版本见同目录的 `requirements-rul-pilot.txt`。主仓库的 `requirements.txt` 没有改动。
