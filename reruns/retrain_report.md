## 1. 逐值比对

13 个输出 CSV 的行数、列名和全部文本列都与冻结结果完全一致。比对明细见 `primary_benchmark_comparison.csv` 和 `primary_benchmark_metric_diffs.csv`。

| 指标（主分析，18 组汇总、1188 个电芯、90 个折） | 最大绝对差 | 最大相对差 |
| --- | --- | --- |
| MAE_Q（电芯级） | 2.4e-15 | 7.1e-14 |
| RMSE_Q（电芯级） | 2.6e-15 | 6.8e-14 |
| R²_Q / R²_SOH（电芯级） | 2.5e-14 | 3.1e-14 |
| MAE_SOH，百分点（电芯级） | 2.0e-13 | 7.1e-14 |
| RMSE_SOH（电芯级） | 2.1e-15 | 6.7e-14 |
| 汇总表中的 Median/Q1/Q3/IQR/Mean | ≤ 2.0e-14 | ≤ 9.4e-14 |
| 预测值，140.9 万行 | 2.0e-14 | 1.8e-14 |
| 次要分析（XJTU initial_test，47 个电芯） | 0 | 0 |

- **排名：** 每组的模型排名完全一致，排名稳定性表的文本列也一致；模型参数哈希相同。
- **超过 1e-10 的两个数：**
  - `Training_Seconds` 是墙钟耗时，本来就会不同，不属于结果。
  - `qref_paired_effects` 的最大相对差为 5.9e-10，但对应的绝对差只有 4.7e-15。原因是这些是两个接近相等的数相减得到的差值，本身接近 0，相对差被放大了。所有结果数值的最大绝对差为 2.0e-13，没有超过 1e-10。
- **残余差异的来源：** RF 和 GB 的预测与冻结结果**逐位相同**（固定种子 20260928，`n_jobs=1`）。差异只出现在 Ridge 上：约 38% 的预测有差，最大 1.5e-14。
  - Ridge 的求解依赖 OpenBLAS 矩阵运算。本机 OpenBLAS 0.3.34 / 0.3.31 默认开 20 个线程，Haswell 内核。多线程会改变浮点求和的顺序，从而在末位产生差异。
  - 冻结运行时的 BLAS 线程数和 CPU 都没有记录，所以无法逐位复现。这与随机种子和依赖版本无关：两边的依赖版本相同，Ridge 也没有随机性。
  - 如果需要 Ridge 逐位可复现，应固定 `OPENBLAS_NUM_THREADS` 并把它写进日志。

## 3. 容量误差换算方式的敏感性

使用同一批重训得到的 SOH 预测值，用三种方式换算成 Ah，再按流水线的口径计算 MAE_Q（先算每个电芯，再取电芯间中位数）。现有做法的重算值与流水线结果相差不超过 1.3e-15。

- **OWN**：乘以测试电芯自己的 Q_ref，即现有做法。
- **NOM**：乘以标称容量。
- **TRAIN**：乘以训练折电芯 Q_ref 的中位数。这是额外加的对照，完全不用测试电芯的信息。

nominal 参考下三种方式结果相同。下表是两个实测参考下的中位 MAE_Q（Ah），顺序为 RF / GB / Ridge：

| 数据集与参考 | OWN | NOM | TRAIN |
| --- | --- | --- | --- |
| XJTU first | 0.0243 / 0.0269 / 0.0381 | 0.1227 / 0.1222 / 0.1284 | 0.0285 / 0.0302 / 0.0397 |
| XJTU first5 | 0.0246 / 0.0269 / 0.0332 | 0.0877 / 0.0913 / 0.1040 | 0.0322 / 0.0304 / 0.0404 |
| HUST first | 0.0203 / 0.0215 / 0.0321 | 0.0748 / 0.0783 / 0.0787 | 0.0226 / 0.0225 / 0.0309 |
| HUST first5 | 0.0203 / 0.0219 / 0.0322 | 0.0741 / 0.0764 / 0.0780 | 0.0213 / 0.0223 / 0.0313 |
| nominal（对照，XJTU / HUST） | 0.0248 / 0.0265 / 0.0341；0.0210 / 0.0228 / 0.0319 | 同左 | 同左 |

**结论有变化：**

1. **按标称容量换算不能用来评价实测参考：** 实测参考下的 MAE_Q 会膨胀 3–5 倍，XJTU 在 0.088–0.128 Ah，HUST 在 0.074–0.079 Ah。膨胀主要来自 Q_ref 与标称容量之间的系统偏差（XJTU 约 −6%，HUST 约 +7%），而不是模型拟合本身。这恰好说明现有的 MAE_Q 很大程度上依赖“已知测试电芯的 Q_ref”。
2. **Ridge 始终排最后，但 RF 和 GB 的先后不稳健：**
   - NOM 下，XJTU first 中 GB 排在 RF 前面（相差 0.0005）。
   - TRAIN 下，XJTU first5 中 GB 排在 RF 前面（相差 0.0017）；HUST first 中 GB 也排在 RF 前面（相差 0.00004）。
   - 论文中“三种模型排名不随参考改变”这一说法只在现有换算方式下成立。
3. **论文里“实测参考下容量误差也下降”的解释依赖现有换算方式：**
   - 改用不含测试电芯信息的 TRAIN 换算后，XJTU 各模型在实测参考下的 MAE_Q 全部**高于** nominal：RF 为 0.0285 和 0.0322，对比 0.0248。
   - HUST 的 RF 在两个实测参考下也高于 nominal：first 0.0226、first5 0.0213，对比 0.0210。GB 仍略低于 nominal：0.0225 和 0.0223，对比 0.0228。
   - 所以简报中“HUST RF/GB 的 SOH 误差下降，是因为容量误差也下降了”这一表述，需要说明这是在使用测试电芯自身 Q_ref 换算的前提下得到的。
