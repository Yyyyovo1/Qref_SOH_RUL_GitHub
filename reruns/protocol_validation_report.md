## 陷阱 A：把噪声当成排名变化

- **RUL：** 在两个设置都可估计的 1476 次比较中，共有 73 次表面排名变化，其中只有 13 次是受支持的反转，即 v2 已报告的 E1 7 次和 E2 6 次。
- **XJTU：** 28 次表面变化中没有一次受支持；其中 27 次出现在 θ ≥ 0.85，因为 XJTU 的 E1 和 E2 只在高 θ 下可估计。
- **噪声基线（主指标：单次重抽样之间点估计排名不一致的比例，设置间取平均）：**

  | 范围 | 不一致比例 |
  | --- | --- |
  | SOH OWN | XJTU 3.7%、HUST 6.5% |
  | SOH TRAIN | 约 12% |
  | SOH NOM | 18–23% |
  | SOH A8 | 16% |
  | RUL | XJTU 10.4%、HUST 4.5%、MIT 4.7% |

  辅助指标（前后两半各取中位数后比较）几乎都是 0，最大的是 HUST RUL 的 0.3%。这说明 5000 次重抽样足够，排名的不稳定来自电芯抽样，而不是重抽样次数不够。
- **S7 口径（只作描述）：**
  - 所有 RUL 比较平均只有 7% 的重抽样会出现符号不同；
  - 但在出现表面变化的比较中，这个比例平均达到 66%。
  - 也就是说，表面变化几乎都发生在排名本来就像抛硬币的设置里。
- **SOH 主范围：** 常见做法和按规范的做法都给出 0 次（事先已知）。按事先约定，这一子项标注为“仅有理论依据，本研究数据未显示差别”。补充范围中的 8 次表面变化全部不受支持。

## 陷阱 B：没有声明评价时使用的信息条件

- 12 个设置中有 3 个的结论取决于信息条件：XJTU 的 RF first、RF first5、GB first。它们在 OWN 下都无法判定，在 TRAIN 下都是“升高”。另外 9 个设置在两种条件下都无法判定。
- 点估计方向（只作描述）有 6 个设置在两种换算下相反：XJTU RF first、RF first5、Ridge first5，以及 HUST RF first、RF first5、Ridge first。
- 这一陷阱的作用是**掩盖差异**：只报告 OWN 时，看不到 XJTU 树模型在实测参考下误差显著升高。
- 规范的要求是声明信息条件，并同时报告两种换算。

## 陷阱 C：删失指标有偏

- **反转次数：**
  - 单侧误差：2 次，都在 HUST θ=0.95 的 TRAJ−BASE；
  - C 指数：6 次（HUST θ=0.94 的 RF−TRAJ，MIT θ=0.81–0.82 的 RF−WAFT）；
  - 两组之间没有任何重合。
- **“预测值更大的方法被判为更优”的比例：** 单侧误差下为 27.6%（736 个可判定设置），C 指数下为 49.7%（768 个设置）。
- **结果与预期方向相反。** 原因是“预测值更大”的方法大多是 TRAJ：在单侧误差下的 736 个设置中占 406 个。TRAJ 的预测远大于真实 RUL，在精确电芯上的误差很大，所以几乎从不被判为更优（单侧误差下 0.5%）。只看 RF 和 WAFT 时，两种指标下“更大者更优”的比例都在 89–99%，没有差别。
- **结论：**
  - 在 v2 的数据中，常见做法给出 2 次反转，按规范做为 0 次，差别很小；
  - 方案预期的“单侧误差偏向大预测值”这一机制没有得到支持；
  - v1 中 E3 的 30 次反转来自不同的设计（单个 t₀、有无校准信息两种条件），不能直接用来补足 v2 的证据。
  - 严格来说，事先约定的标注条件（两种做法结果相同）没有被触发，因为 2 ≠ 0；但这一陷阱在本研究数据中的证据较弱，写规范文档时需要如实说明。

## 陷阱 D：端点规则的差异

- 本项只比较标签数量和 EOL 循环数，不检验容差规则是否改变 RUL 方法的排名。
- **标签数量：** 63 个设置合计，容差规则与严格规则的有标签电芯数为：

  | 数据集 | 容差规则 | 严格规则 |
  | --- | --- | --- |
  | XJTU | 2274 | 736 |
  | HUST | 4462 | 4352 |
  | MIT | 6123 | 5792 |

  - 仅由容差判定产生的标签：XJTU 305、HUST 113、MIT 355。
  - XJTU 差别最大，主要因为严格规则下的区间删失（1328 个设置）在容差规则下变成了点标签：1166 个来自插值，162 个来自容差判定。
- **对论文主结论的直接影响（θ = 0.80）：**

  | 数据集 | 参考 | 严格规则 | 容差规则 |
  | --- | --- | --- | --- |
  | HUST | nominal / first / first5 | 0 / 77 / 77 | 77 / 77 / 77 |
  | XJTU | nominal / first / first5 | 20 / 0 / 0 | 54 / 1 / 5 |
  | MIT | nominal / first / first5 | 43 / 43 / 43 | 124 / 46 / 46 |

  - IJPHM 简报中“HUST 精确 RUL 资格从 0 升到 77”的结论，在容差规则下不再成立：三种参考都是 77。HUST 的 77 个 nominal 标签全部来自容差判定，这与 HUST 记录停在 nominal 80% 附近一致。
  - XJTU 的变化在容差规则下依然存在，方向相同，幅度更大。
  - MIT 在严格规则下三种参考都是 43，在容差规则下变为 124 / 46 / 46。
- **EOL 循环数（两种规则下都有标签时，容差规则 EOL 减严格规则 EOL）：**

  | 数据集 | 中位数 | |差| ≤ 1 的比例 | 最大值 |
  | --- | --- | --- | --- |
  | XJTU | −0.34 | 98.2% | 5.7 |
  | HUST | −0.51 | 99.5% | 4.5 |
  | MIT | −0.46 | 92.8% | 669 |

  中位数为负，是因为插值使交点略早于严格规则的首个低于阈值的观测。

- MIT 有 418 个设置（51 个电芯）差值大于 1 个循环，其中 288 个的严格 EOL 正好落在批次 2 被标记的单循环下凹上。容差规则的平滑去掉了这些下凹，而严格规则把它们当成了首次到达。
- 所以两种规则各有代价：严格规则不把未穿越阈值的电芯算作到达 EOL，但对单循环噪声敏感；容差规则稳健于噪声，但会把停在阈值附近的记录算作到达 EOL。

## 对论文和规范文档的含义

1. **陷阱 A（RUL）和陷阱 D 都在本研究数据中有明确表现。** RUL 的表面排名变化有 82% 不受支持（73 次中 60 次）。端点规则可以改变“哪个参考下有精确 RUL 标签”这一核心结论：HUST 在 θ=0.80 的 0 → 77。
2. **陷阱 B 有明确表现，但方式是掩盖而不是制造差异。**
3. **陷阱 C 在 v2 数据中证据较弱，** 预期的偏向机制没有得到支持。
4. **陷阱 A 的 SOH 主范围没有表现出差别，** 按事先约定标注为“仅有理论依据，本研究数据未显示差别”。
5. **最需要注意的是陷阱 D 对 IJPHM 简报的影响。** 简报把 HUST 的 0 → 77 作为主要发现之一。本分析显示，这一结果依赖于“不使用容差判定”这一端点规则；换成已发表文献中使用的容差规则后，HUST 的变化消失，XJTU 的变化仍然存在。下一版稿件需要把端点规则作为结论的前提条件明确写出，并报告两种规则下的结果。
